# UR5 PyBullet asset

The URDF and mesh files are based on the `robotflow` branch of
[`ElectronicElephant/pybullet_ur5_robotiq`](https://github.com/ElectronicElephant/pybullet_ur5_robotiq).
The visual mesh references in `ur5.urdf` were adjusted from `.dae` to the
included `.obj` files so that PyBullet can load this asset without ROS.

The original repository's BSD-style license applies to these files.
